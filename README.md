# LessonPlanGen

A Vue.js application for generating lesson plans with framework support. Built with Vue 3, TypeScript, and Vuetify.

## Features

- Framework-specific lesson plan creation
- Support for multiple educational frameworks:
  - WIDA Standards
  - Common Core
  - Next Generation Science Standards
- Dynamic form generation
- Real-time validation
- Responsive design
- TypeScript for enhanced type safety

## Project Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

- `src/components/` - Vue components
  - `Frameworks/` - Framework-specific form components
  - `LessonPlan/` - Core lesson plan components
- `src/store/` - Vuex store modules
- `src/services/` - API and data services
- `src/constants/` - Application constants

## Technology Stack

- Vue 3
- TypeScript
- Vuex
- Vuetify
- Vite
